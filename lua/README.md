# lua Dockerfile

## Includes 

- lua (https://www.lua.org/)

- luarocks (https://www.luarocks.org/) (Lua package manager)



## Default Version lua

Default lua version : 5.4.1


## get this image

you can execute following command to get this docker image :

docker pull mgrafr/docker-lua # docker.io

ghcr.io pull  mgrafr/docker-lua # github
